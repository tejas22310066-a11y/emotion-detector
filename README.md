# Emotion Detector

This repository contains the final project for the AI-based web application that detects emotions from user input text using the Watson NLP library.

## Features
- Detects emotions from text input
- Returns scores for anger, disgust, fear, joy, and sadness
- Identifies the dominant emotion
- Web deployment using Flask
- Unit testing included
- Static code analysis using pylint

## Technologies Used
- Python
- Flask
- Watson NLP API
- Requests
- Unittest
